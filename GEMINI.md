# VNCNT Labs tools

These MCP servers run VNCNT Labs tools on Apify. Every tool call is a paid run on the user's Apify account, priced per result.

- Before a large call (many keywords, domains or pages), say roughly how many results it will return and confirm with the user.
- Start with small limits and raise them only if the user wants more.
- Tool names look like `vncntlabs--<tool>`. Each tool's description lists its input fields.
- Groups: vncntlabs-seo (SEO & Search Data); vncntlabs-seller (Seller Tools); vncntlabs-video (YouTube Data); vncntlabs-local (Local & Market Data); vncntlabs-fee (Fee & Profit).
